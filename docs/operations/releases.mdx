Zeabur Builder has no releases yet. This page describes the artifacts and signatures that the release workflow on the `main` branch will produce when it runs. You can use `cosign verify` to verify an image's signature before installing it.

## Release workflow

A `v<version>` tag triggers the release workflow:

- Build images for `linux/amd64` and `linux/arm64`, and run smoke tests on a k3s cluster.
- Publish `ghcr.io/zeabur-oss/builder`, `builder-job`, and `builder-railpack` to the registry by digest.
- Pin these image digests in the chart, and push the chart to `oci://ghcr.io/zeabur-oss/charts/zeabur-builder`.
- Sign all images and the chart with Sigstore's keyless signing.

After the workflow completes, maintainers publish the draft release.

## Verify an image

Before installing, replace `<digest>` with the image's digest and `<version>` with the corresponding version, then run:

```sh
cosign verify ghcr.io/zeabur-oss/builder@sha256:<digest> \
  --certificate-identity https://github.com/zeabur-oss/builder/.github/workflows/release.yml@refs/tags/v<version> \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```
