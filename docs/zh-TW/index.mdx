Zeabur Builder 是一個 Kubernetes operator。你寫一個 `Build` 指向 Git 儲存庫，它為每個新 commit 建置映像檔，推送到映像檔倉庫，並把 `<repository>:<tag>@<digest>` 寫進 `status.latestImage`。

Zeabur Builder 只建置映像檔。測試、部署與日誌儲存交給你的 pipeline、部署工具與日誌收集工具。

<Callout type="info">

Zeabur Builder 還沒有發行版，API 是 `v1alpha1`。這份文件描述 `main` 分支現在的行為。

</Callout>
