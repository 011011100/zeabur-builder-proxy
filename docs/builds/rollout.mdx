---
title: Deploy built images
description: Use sortable tags with deployment tools, and configure Build to notify Keel after a successful build.
---

Use sortable tags so Flux image automation, Argo CD Image Updater, and Keel can pick up new images when they poll the image registry. With `spec.notify` configured, `Build` notifies Keel after each successful build, so you don't have to wait for polling.

## Tag format

Each build generates a tag that contains the branch name, Unix time, and commit, in that order:

```text
main-1761058800-3e1a9c2
```

These tags are sortable, with the latest tag last. You can customize tags with `spec.output.tagTemplate` and `extraTags`.

Zeabur Builder builds and pushes images. Your deployment tool handles deployment.

## Notify Keel

Add a Keel webhook to `spec.notify` in your `Build`:

```yaml
spec:
  notify:
    - {type: keel, url: http://keel.keel.svc:9300/v1/webhooks/native}
```

After each successful build, the controller sends the following payload:

```text
{"name": <repository>, "tag": <tag>}
```

`name` is the image repository, and `tag` is the tag generated by the build. The controller makes up to 3 attempts and records the notification result as an Event on the `Build`.

## Verify the result

Check the Events on the `Build` to verify the Keel notification result.
